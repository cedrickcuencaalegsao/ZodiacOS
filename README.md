# ZodiacOS

**A Unix-inspired operating system built from scratch with Rust and Assembly.**

ZodiacOS is an independent operating system project focused on security, reliability, performance, and a unique computing philosophy. It aims to build a modern operating system with its own kernel architecture, filesystem, package management, and application ecosystem.

## Project Components

- **ZodiacOS Kernel** — The core of the operating system, developed using Rust and Assembly.
- **ZodiacFS** — The native filesystem architecture of ZodiacOS.
- **ZPM** — ZodiacOS Package Manager for applications, drivers, and extensions.
- **ZPM Repository** — A package repository for distributing ZodiacOS software.

## Project Goals

- Build an independent Unix-inspired operating system.
- Prioritize security through isolation and explicit permissions.
- Develop a native filesystem and package management ecosystem.
- Support a modern application and driver architecture.
- Provide an open platform for third-party developers.
- Build a reliable and extensible operating system from the ground up.

## Development

ZodiacOS is actively under development. Features, interfaces, and architectural decisions may evolve as the project progresses.
